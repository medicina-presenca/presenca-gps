# 🎯 INSTALAÇÃO SUPER FÁCIL - SEM PROGRAMAÇÃO

## 📱 OPÇÃO 1: USAR ONLINE (MAIS FÁCIL - RECOMENDADO)

Vou te ajudar a colocar online usando serviços gratuitos que fazem TUDO automaticamente!

### Passo 1: Criar conta no Railway (GRÁTIS)

1. Acesse: https://railway.app
2. Clique em "Start a New Project"
3. Faça login com sua conta Google ou GitHub
4. Pronto! Você tem uma conta

### Passo 2: Fazer Upload do Projeto

**OPÇÃO A - Usando GitHub (Recomendado):**

1. Crie conta no GitHub: https://github.com/signup
2. Clique em "New Repository"
3. Nome: `presenca-gps`
4. Marque "Public"
5. Clique "Create repository"
6. Faça upload de TODOS os arquivos do projeto
7. No Railway, clique "New Project" → "Deploy from GitHub repo"
8. Selecione o repositório `presenca-gps`
9. PRONTO! Railway instala tudo automaticamente!

**OPÇÃO B - Usando template direto:**

1. Eu vou te dar um link de template pronto
2. Você clica no link
3. Railway cria tudo automaticamente
4. Em 5 minutos está no ar!

### Passo 3: Configurar (Railway faz automaticamente)

Railway vai te perguntar:

1. **Database**: Clique em "Add MySQL" (GRÁTIS)
2. **Variáveis**: Railway mostra uma lista, você só preenche:
   - `ALLOWED_EMAIL_DOMAINS`: coloque seu domínio (ex: unifacig.edu.br)
   - `JWT_SECRET`: Railway gera automaticamente
3. Clique "Deploy"

### ✅ PRONTO! Seu site está no ar!

Railway te dá um link tipo: `https://seu-app.railway.app`
